Atik: A Shared-Mesh Transformer Accelerator for RISC-V Atik：面向RISC-V的共享阵列Transformer加速器

Ahmed Zeer, Erkan Uslu

arXiv:2611.09522 · 2026-11-06T14:36:37Z

Atik uses one fixed-point MAC mesh for matrix multiplication and dense attention, accepts BF16 tensors, and streams online softmax without materializing the full attention-score matrix. In cycle-by-cycle FireSim evaluation, the 8×8 mesh reaches peak speedups of 31.5× for matrix multiplication and 225.8× for attention against a scalar Rocket BF16 reference. Sharing the datapath offers a concrete way to support both kernels with the same compute resources. The preprint combines simulation with standalone Sky130 physical design; its model-level speedups are hybrid projections rather than full-model hardware runs. Atik以同一套定点乘加阵列执行矩阵乘法与稠密注意力，输入输出采用BF16，并通过流式在线softmax避免显式保存完整注意力分数矩阵。在逐周期FireSim评估中，8×8阵列相对标量Rocket BF16参考实现，矩阵乘法和注意力的峰值加速分别达到31.5倍和225.8倍。共享数据通路为使用同一组计算资源支持两类内核提供了具体方案。该预印本结合模拟与独立的Sky130物理设计评估，模型级加速来自混合推算，并非完整模型的硬件实跑结果。

Retraining-Free Accuracy Recovery for Analog Compute-in-Memory 无需重新训练的模拟存算一体精度恢复

George Karfakis, Puneet Gupta

arXiv:2611.08693 · 2026-11-05T20:49:55Z

Input centering, array-local Hadamard rotations and shared calibration let pretrained models compensate for analog-array errors without updating their weights. On the evaluated ReRAM configuration with 6-bit ADCs, the preprint reports accuracy recovery from 37.4% to 82.9% for ViT-B/16 and from 27.0% to 72.2% for Phi-4, both within 2.2 percentage points of floating-point accuracy. The method could reduce the cost of hardware-aware retraining, with applicability dependent on the target array's error distribution and calibration conditions. 研究结合输入中心化、限制在阵列内部的Hadamard旋转和共享校准，使预训练模型无需更新权重即可补偿模拟阵列误差。在所评估的6比特ADC ReRAM配置上，预印本报告ViT-B/16准确率从37.4%恢复至82.9%，Phi-4从27.0%恢复至72.2%，两者与浮点准确率的差距均不超过2.2个百分点。该方法有望降低硬件感知重新训练的成本，其适用性取决于目标阵列的误差分布与校准条件。

CAMP: Context-Aware LLM Weight Placement on 3D-IMC Arrays CAMP：面向3D存算一体阵列的上下文感知大模型权重放置

Orhun Görkem, Athanasios Vasilopoulos, Georgios Pagonis, et al.

arXiv:2611.07707 · 2026-11-05T09:27:31Z

CAMP places LLM weights across stacked 3D-IMC arrays using a conflict matrix that captures contention among the architecture, network and inference context. A profiling-driven feedback loop refines the mapping to expose concurrent matrix-vector operations and improve resource use. The contribution makes weight placement an execution-scheduling decision, with benefits that need to be evaluated for each architecture and runtime context. CAMP通过冲突矩阵描述硬件架构、模型网络与推理上下文共同引发的资源争用，据此将大模型权重放置到堆叠的3D存算一体阵列中。以性能分析驱动的反馈循环进一步优化映射，使更多矩阵向量运算能够并发执行，并改善资源利用。该研究将权重放置转化为执行调度问题，具体收益需要结合各类架构与运行时上下文评估。

Gain-Dependent Entropy in a Zener Avalanche Noise TRNG 齐纳雪崩噪声真随机数发生器中的增益相关熵特性

Rishabh Das

arXiv:2611.08774 · 2026-11-05T22:51:58Z

This circuit study assesses five amplifier-gain settings and two coupling-capacitor values in a Zener avalanche noise generator, using 1.44 billion raw bits per configuration for NIST SP 800-22 and SP 800-90B evaluation. Replacing the diode with a stable voltage source at the same bias point reduces switching activity by about 97%, supporting avalanche noise as the necessary entropy source. A three-phase autocorrelation pattern associated with comparator saturation and recovery makes analog circuit dynamics a key consideration in entropy assessment for low-cost embedded hardware. 该电路研究评估齐纳雪崩噪声发生器的5种放大器增益与2种耦合电容取值，每种配置采用14.4亿原始比特进行NIST SP 800-22与SP 800-90B评估。将二极管替换为相同偏置点的稳定电压源后，开关活动减少约97%，支持雪崩噪声是必要熵源的判断。研究发现与比较器饱和及恢复过程相关的三阶段自相关结构，说明模拟电路动态是评估低成本嵌入式硬件熵质量的重要因素。

BitDecoding-FP4: Native FP4 KV Cache Decoding BitDecoding-FP4：原生FP4 KV缓存解码

Dayou Du, Woon Yee Ng, Guangming Sheng, et al.

arXiv:2611.09825 · 2026-11-06T18:13:54Z

BitDecoding-FP4 co-designs quantization and attention kernels to decode directly from FP4 KV caches while addressing query error, probability underflow and key outliers. Splitting queries into two FP4 tensors reduces the reported query-logit error from 60% to 1%; the system also fuses probability quantization into transposed softmax and stacks query matrix operations over paged caches. The preprint targets the accuracy and kernel-overhead barriers that can prevent nominal 4-bit memory savings from becoming useful decoding throughput. BitDecoding-FP4协同设计量化算法与注意力内核，直接使用FP4 KV缓存进行解码，并处理查询量化误差、概率下溢和键值离群点。将查询拆分为两个FP4张量后，文中报告的查询logit误差从60%降至1%；系统还将概率量化融合到转置softmax中，并在分页缓存上堆叠查询矩阵运算。该预印本针对精度损失与内核开销展开优化，这两类问题会妨碍4比特缓存的理论存储收益转化为实际解码吞吐量。

CHARM+: Attention Scheduling Across Unequal Communication Links CHARM+：面向带宽不均衡互连的注意力调度

Xinhang Zhang, Boning Zhang, Chengchun Liu, et al.

arXiv:2611.05906 · 2026-11-04T03:57:56Z

CHARM+ reorganizes sequence-parallel attention communication into levels and separates cross-hardware transfers from local communication to reduce synchronization caused by unequal bandwidth. Against Ring-Attention, the preprint reports average forward/backward speedups of 1.3×/1.7× on a dual-NUMA PCIe architecture and 2.8×/2.9× on a dual-node NVLink architecture. The different gains show why communication scheduling needs to reflect the actual interconnect topology; these are attention-algorithm results rather than whole-model speedups. CHARM+将序列并行注意力通信重组为多个层级，并分离跨硬件传输与本地通信，以减少带宽不均衡引发的同步开销。相对Ring-Attention，预印本报告双NUMA PCIe架构上的前向与反向平均加速分别为1.3倍和1.7倍，双节点NVLink架构上分别为2.8倍和2.9倍。收益差异说明通信调度需要匹配实际互连拓扑；这些数字衡量注意力算法性能，尚不能直接等同于完整模型加速。

SAFTAC: Simulation-Augmented LLM Training for Analog Circuit Design SAFTAC：以仿真增强大模型训练的模拟电路设计方法

Junsheng Huang, Yifan Sun, Zhuoer Zhang, et al.

arXiv:2611.08543 · 2026-11-05T03:54:10Z

SAFTAC builds a simulation-grounded dataset of 8,626 design tasks across 10 analog-circuit types, including specifications, labeled ports, loads, testbenches and reference netlists. It combines three-stage supervised fine-tuning with reinforcement fine-tuning augmented by simulation feedback so open-source LLMs can generate and revise designs against explicit requirements. The work addresses missing training information for specification-driven design, while physical implementation and fabricated performance require subsequent validation. SAFTAC构建了以仿真为基础的数据集，包含10类模拟电路的8626项设计任务，并提供指标要求、标注端口、负载、测试平台和参考网表。它结合三阶段监督微调与仿真反馈增强的强化微调，使开源大模型能够依据明确要求生成并修改设计。该工作补充了指标驱动设计所缺少的训练信息，物理实现与流片后的性能仍需后续验证。

TauLang: Explicit Space-Time Programming for Static Accelerators TauLang：面向静态调度加速器的显式时空编程

Xuxiao Yang, Junchi Wu, Yuqi Peng, et al.

arXiv:2611.06079 · 2026-11-04T07:21:03Z

TauLang makes operation issue times explicit in a kernel language for statically scheduled accelerators, where cycle timing is part of program correctness. Its compiler checks timing relationships algebraically and jointly solves tensor placement and cycle scheduling with integer linear programming. The approach could make schedule exploration easier on TSP-style machines, with evaluation conducted on a cycle-accurate TSP-like model rather than establishing performance on deployed Groq hardware. TauLang在面向静态调度加速器的内核语言中显式表达操作发射时间，因为这类机器的周期时序直接关系到程序正确性。编译器通过代数方式检查时序关系，并以整数线性规划联合求解张量放置与周期调度。该方法有望简化TSP类架构的调度探索，评估采用类似TSP机器的周期精确模型，其结果尚不能直接代表已部署Groq硬件的性能。

RoadBlock Models Microscaling Formats Inside Programmable Tensor Cores RoadBlock在可编程Tensor Core中建模微缩放数值格式

Nikhil Rout, Blaise Tine

arXiv:2611.08526 · 2026-11-04T01:17:32Z

RoadBlock is an open-source framework built on the RISC-V Vortex GPGPU that models custom microscaling formats inside a programmable Tensor Core. It exposes data width, scale-factor width and block size as parameters and derives per-thread metadata tiling, enabling perplexity and power-performance-area tradeoffs to include integration overhead. The tool supports format selection before committing to silicon, with its results serving as modeling evidence that still needs physical validation. RoadBlock是基于RISC-V Vortex GPGPU构建的开源框架，可在可编程Tensor Core中建模自定义微缩放数值格式。它将数据位宽、缩放因子位宽与分组大小参数化，并推导每个线程的元数据分块方式，使困惑度与功耗、性能、面积的权衡能够纳入集成开销。该工具支持在确定芯片实现前筛选格式，其结果属于建模证据，仍需物理实现验证。
