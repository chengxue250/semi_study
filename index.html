Wccftech · 8h ago Wccftech · 8小时前

Middle-end-of-line constraints still limit the practical path to roughly 5nm-equivalent integration, so the result is a device advance rather than proof of a production-ready 3nm process. 中国科学院据报开发出开关比超过500,000的全环绕栅极（GAA）晶体管，并以DUV光刻实现被描述为接近3nm级的器件性能。中段制程（MEOL）约束仍将实际集成路径限制在约5nm等效水平，因此这更接近器件层面的进展，而非可量产3nm制程的证明。
